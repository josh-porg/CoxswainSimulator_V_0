# Coxing-call ratings

A small static site where invited rowers and coxswains rate coxswain calls for a research study: a few short calls a
day, then a few muffled voice clips.

The calls and clips in this repository are encrypted (AES-256-GCM). They can only be opened with the key carried in
the personal study link, after the `#`, which browsers never send to any server. `manifest.json` holds only opaque
codes. Ratings are stored by the study lead through a Google Apps Script (`Code.gs`), which accepts them only from
people holding the link.

This repository is generated by the study's build script; please don't edit it by hand.
